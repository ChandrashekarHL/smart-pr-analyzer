## Invariants — do not break
- Tokenizers load only through `prana.compat.load_tokenizer`. On transformers 5 `AutoTokenizer` returns a DeepSeek variant that strips all whitespace; we lost a 10-hour run to it.
- The prompt is `prana/prompts.py` only; its fingerprint is written into every adapter and checked at serve time.
- Bot removal is by `reviewer` field, never comment text (Copilot and Codex are indistinguishable from humans by text).
- Splits are by PR and by repo (`test_ood`); never random by row. `test_ood` is the number to report.
- Never score ROUGE/BERTScore on serialised JSON — parse and score per field.
- `data/train_v2` is current (filters v2). `data/train` is v1, kept for traceability. Public/permissive-only variant is built with `--out data/public` (no `--allow-any-license`).

## Editing on Windows, running on Linux
- Write every file with **LF** endings. A Python patch using `Path.write_text` on Windows silently produces CRLF, and `bash` on the Spark then fails with `set: pipefail: invalid option name` (this killed the base-eval job on 2026-10-19). Use `write_text(..., newline="\n")` or `write_bytes`. `tests/test_repo_hygiene.py` fails on any CRLF file.

## Long jobs on the Spark
- Launch detached: `setsid nohup bash scripts/<x>.sh > runs/<x>.log 2>&1 < /dev/null &`. Never tmux for unattended runs (a Ctrl-C in an attached client killed a 16-hour run).
- Never `pgrep`/`pkill` by command text over SSH — it matches the SSH command itself. Use PIDs.
- Status files: `runs/STATUS*`. Spark clock is **UTC**; user is in IST (+5:30).
